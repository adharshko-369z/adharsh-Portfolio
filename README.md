# Adharsh K O - Portfolio

A responsive frontend portfolio website, designed in Figma and built with Vite, React and TypeScript, that showcases my projects and skills and makes it easy for anyone interested in hiring me to get in touch.

**Live:** [adharsh-ko.netlify.app](https://adharsh-ko.netlify.app/)

**Design:** [Figma](https://www.figma.com/design/nXXpbIPVGhUuot23EEQrhJ/Portfolio?node-id=0-1&t=9uUcpDQ5JDArsLF2-1)

## Tech stack

- React
- TypeScript
- Vite
- CSS (design tokens)
- Vitest
- ESLint

## Run locally

```bash
npm install
npm run dev
npm run lint
npm run test
npm run build
```
